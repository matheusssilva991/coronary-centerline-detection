# Segmentation Output Layout

This folder separates raw pipeline runs, canonical result pointers, numeric
analysis outputs, and visual examples.

## Runs

New pipeline executions are saved under:

```text
output/segmentation/runs/<resolution>_res/<timestamp>/
```

Each run uses this structure:

```text
config/
  effective_pipeline_config.json
  split_ids.json
logs/
  pipeline.log
numeric/
  ostios_<split>_summary.csv
  ostios_<split>_metadata.json
  ostios_<split>_lote_<n>_summary.csv
visual/
  ostia_examples/
  artery_examples/
  hough_examples/
```

Use `numeric/` for CSV/JSON files generated by the pipeline. Use `visual/` for
HTML, PNG, or interactive examples associated with that specific run.

## Canonical

`canonical/` is reserved for stable references to the result folders used by
EDA notebooks and comparisons. Prefer pointing each split to the numeric
directory of the chosen run:

```text
canonical/
  mid_res/
    train/
    val/
    test/
  high_res/
    train/
    val/
    test/
```

The notebooks still fall back to the legacy `8.final_results/` folders when no
canonical directory exists.

## Analysis

Derived notebook outputs live under:

```text
analysis/
  bad_cases/
  cases_analysis/
  ia_vs_math/
  resolution_comparison/
  subset_reports/
  visual_examples/
```

Use this area for comparisons, sampled cases, plots, and exported tables that
were not produced directly by a full pipeline run.

## Legacy

`8.final_results/` and `val_diff/` are legacy result folders. Keep them as
historical references unless a specific migration is needed.
