# Catálogo de casos ruins

Arquivos compactos produzidos pela análise quantitativa de falhas em resolução
média.

- `bad_cases_test_mid_res.csv`: tabela para inspeção e filtragem;
- `bad_cases_test_mid_res.json`: mesma seleção em formato estruturado.

Esses arquivos servem de entrada para análises qualitativas. Eles não contêm
novas máscaras e não substituem os summaries originais em `runs/`.
