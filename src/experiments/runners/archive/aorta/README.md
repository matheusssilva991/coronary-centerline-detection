# Runners históricos de aorta

Estes scripts reproduzem variações já encerradas: controlador isolado, envelope
sem a proteção atual e combinações que não apresentaram ganho agregado. Eles
permanecem apenas para auditoria e não são a interface recomendada para novos
testes.

Use `src/experiments/runners/run_aorta_filter_envelope_generalization.sh` para
os próximos experimentos do filtro de trajetória e do envelope.
