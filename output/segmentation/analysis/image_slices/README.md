# Fatias de imagens

Figuras axiais exportadas pelos notebooks de visualização. O nome registra o ID
do exame e o índice da fatia, por exemplo:

```text
image_90_axial_slice_0137.png
```

Esta pasta deve conter apenas figuras realmente usadas fora do notebook, como
imagens de artigo ou inspeções selecionadas. Visualizações exploratórias devem
permanecer somente como saída temporária das células.
